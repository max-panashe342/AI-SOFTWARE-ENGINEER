# AI ERA INTERNSHIP

AI ERA INTERNSHIP is an AI-powered simulated professional engineering
workplace. The repository contains the React/Vite frontend, FastAPI backend,
local SQLite development database configuration, and product documentation.

## Permanent product constitution

All future development must follow the [AI ERA Product Constitution](./docs/AI-ERA-PRODUCT-CONSTITUTION.md).
It defines the product vision, architecture principles, AI-agent responsibilities,
security and evidence requirements, engineering workflow, and documentation
standards. Read it before implementing or reviewing project changes.
